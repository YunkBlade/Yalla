# Yalla | Relatórios de Marketing

Painel estático (um único `index.html`) publicado na Vercel.

## Publicar
- Pela Vercel CLI, nesta pasta: `npx vercel --prod`
- Ou suba esta pasta num repositório do GitHub e importe em vercel.com/new (Framework: Other, sem build).

## Atualizar
- Dados mensais: importar em "Importar dados" no painel e enviar o arquivo baixado para incorporação,
  ou substituir o `index.html` por uma versão nova.
- `fonte/` guarda os leitores das planilhas (Meta, Google, Yalla Digital, concorrência).

O painel não contém dados pessoais de clientes (só contagens agregadas).
